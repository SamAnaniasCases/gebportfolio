# 0004.2 Chess Checkmate Handling, Match Reset & Pawn Promotion Specification

<callout icon="doodle/misc/trophy">**Status:** Approved · **Owner:** Sam Ananias Cases · **Created:** 2026-08-13</callout>

This specification outlines the architecture, UI flow, and backend state transitions for adding **Interactive Pawn Promotion**, **Checkmate & Victory State Declarations**, **Piece Identification Hover/Tap QoL Indicators**, **Match Archival, Reset & Team Re-Assignment**, **All-Time vs Match Contributor Metrics**, and **Enhanced Web Audio Synthesis** to the shared Crowd Chess Game.

---

## 1. Objectives & Scope

1. **Interactive Pawn Promotion**: When a player moves a pawn to the 8th rank (or 1st rank for Black), present an in-board popover modal with woodcut-styled piece choices (Queen, Knight, Rook, Bishop) instead of auto-promoting to Queen.
2. **Checkmate & Game Over Declaration**: Properly detect `isCheckmate()`, `isDraw()`, and `isStalemate()`. Replace the generic "King is in Check" alert and "Waiting for..." status with a celebratory "CHECKMATE! Team [White/Black] Wins!" victory banner in both the widget and `GameDetailsModal`.
3. **Smooth Piece Identification QoL (Hover & Tap)**:
   - When hovering over a piece on desktop or tapping/selecting a piece on mobile, smoothly display a non-invasive floating pill badge above the square/piece (e.g. `White Knight (g1)` or `Black Queen (d8)`).
   - Use subtle woodcut theme tokens, `pointer-events-none`, and smooth scale/opacity transitions so it never obscures gameplay on mobile or desktop.
4. **Dual Contributor Metrics (Current Match vs All-Time)**:
   - **Current Match Contributors**: Number of unique visitor sessions who contributed moves to the active match (`seenSessions.length`). Resets to 0 when a new match begins.
   - **All-Time Total Visitors**: Persistent cumulative count of unique visitor sessions who have played on the board across all matches in history (`allTimeContributors`). Never resets!
5. **Match Reset & Team Re-Assignment**: Provide a server-verified reset mechanism (`/api/chess/reset`) allowing crowd players to start a fresh match once a game reaches checkmate or draw. Upon reset, the board reverts to starting position (`INITIAL_FEN`), current match contributors reset to 0, and users are assigned fresh teams for the new match.
6. **Finished Game Archival & Match History**: Automatically archive completed games (PGN, outcome, total moves, contributor count, finished timestamp) to database history, rendering past match records and PGN export inside `GameDetailsModal`.
7. **Synthesizer Sound Effects**: Expand `src/lib/chess/audio.ts` with Web Audio API synthesizers for checkmate victory fanfare and pawn promotion flourishes.

## 2. Proposed Changes & Architecture

### 2.1 Component Layer

#### [`src/components/chess/ChessWidget.tsx`](../../src/components/chess/ChessWidget.tsx)

- Detect when a pawn move targets rank 8 (white) or rank 1 (black) with multiple promotion options (`q`, `n`, `r`, `b`).
- Intercept the move execution to open the `PromotionModal` overlay before calling `/api/chess/move`.
- Render the checkmate/draw banner overlay when `gameState.outcome` or `chess.isGameOver()` is active.
- Wire the "Start New Match" button to trigger `/api/chess/reset`.

#### [`src/components/chess/ChessBoard3D.tsx`](../../src/components/chess/ChessBoard3D.tsx)

- Add mouse hover (`onPointerEnter`/`onPointerLeave`) and tap selection state tracking for piece identification labels.
- Render non-invasive floating piece label pill badge (`White Knight on g1`) with smooth opacity/transform animation over hovered/selected pieces.
- Render the target promotion square popover overlay directly over the board stage.
- Add checkmate king highlight visuals (gold/emerald glowing aura for victory, rose pulse for checkmate target).

#### [`src/components/chess/GameDetailsModal.tsx`](../../src/components/chess/GameDetailsModal.tsx)

- Check `gameState.outcome` to render "GAME OVER - TEAM [WHITE/BLACK] WINS BY CHECKMATE!" status header.
- Display both **Current Match Contributors** (resets per match) and **All-Time Total Visitors** (permanent cumulative metric).
- Add "Archived Matches" section displaying completed match history with outcome, contributor counts, and a "Copy PGN" button.

#### `src/components/chess/PromotionModal.tsx` `[NEW]`

- An in-board popover dialog displaying 4 selectable piece options (Queen, Knight, Rook, Bishop) styled in the Woodcut theme using vector SVG assets.

### 2.2 API & Storage Layer

#### [`src/lib/chess/storage.ts`](../../src/lib/chess/storage.ts)

- Add `seenSessions: string[]` and `allTimeContributors: number` to `StoredGameState` and D1 database schema (`seen_sessions` TEXT and `all_time_contributors` INTEGER columns).
- Maintain permanent `allTimeContributors` count when new unique session IDs submit moves across any match.
- Extend `archiveGame()` to persist completed match records into D1 / memory state and export `getArchivedGames()`.

#### `src/pages/api/chess/reset.ts` `[NEW]`

- `POST /api/chess/reset`: Validates session cookie, checks if current game is over or resets state back to `INITIAL_FEN` (version 0), resets match contributors, archives finished game, and re-assigns team cookies for the new match.

#### `src/pages/api/chess/archive.ts` `[NEW]`

- `GET /api/chess/archive`: Returns past completed games list and PGN data for `GameDetailsModal`.

#### [`src/pages/api/chess/move.ts`](../../src/pages/api/chess/move.ts) & [`src/pages/api/chess/state.ts`](../../src/pages/api/chess/state.ts)

- Pass `game.seenSessions` into `createArbiter()` initialization.
- Support promotion SAN moves (`e8=Q`, `e8=N`, `e8=R`, `e8=B`), trigger `storage.archiveGame()`, and return updated outcome state on checkmate/stalemate.

### 2.3 Audio Synthesizer

#### [`src/lib/chess/audio.ts`](../../src/lib/chess/audio.ts)

- Add `playCheckmate()`: Triumphant C-major chord fanfare synthesizer.
- Add `playPromotion()`: Upward arpeggio flourish synthesizer.
